# رحلة قراءة «مجلة الرسالة» 📜

قراءة يوميّة متجدّدة من [مجلة الرسالة](https://ar.wikisource.org/wiki/مجلة_الرسالة) المصريّة (تصدر منذ ١٩٣٣) —
المتن الأصليّ كامل، وإلى جانبه شرحٌ وحواشٍ للكلمات الصعبة والإشارات التاريخيّة.

**اقرأ اليوم:** 👉 https://almatrouk88.github.io/risala-daily/

- تصميم عالي التباين يصلح للجوّال ولأجهزة الحبر الإلكترونيّ (BOOX وغيرها).
- يُحدَّث تلقائيًّا كلّ صباح عبر وكيل مجدوَل (routine) يتبع [`AGENT.md`](AGENT.md).
- الحالة في [`progress.json`](progress.json)، وأرشيف الأيّام في [`archive/`](archive/).

المحتوى الأصليّ من مجلّة الرسالة (ملكيّة عامّة). الشروح والحواشي مُولَّدة للمساعدة على القراءة.
